## Przygotowanie następnego wydania

`node scripts/build-pv-public.mjs /ścieżka/do/kopii-publicznej-strony`

Polecenie buduje moduł, kopiuje wyłącznie publiczne zasoby do `pv-mining/`, dodaje
CSP i link z karty Smart Home. Nie wykonuje push ani publikacji.
Katalog docelowy musi zawierać publiczną stronę z CNAME `ampower.pl`.
Podstawowy `npm run build` nadal przygotowuje wyłącznie dotychczasowy pakiet strony;
przed zastąpieniem całego publicznego artefaktu trzeba dołączyć PV tym poleceniem.
Nie usuwać modułu podczas przyszłej aktualizacji strony głównej.
